# tanaoroshi-webapp

ハンドメイド作家向けの「年末棚卸し＋売上・経費集計」Webアプリです。
スマホのブラウザで使えるように作られた静的サイトで、バックエンドはありません。データはブラウザの localStorage に保存されます。

## 機能

| 画面 | できること |
| --- | --- |
| ダッシュボード | 売上合計・経費合計・利益・在庫金額、カテゴリ別経費 |
| 棚卸し | 品目名・数量・単価を登録 → 在庫金額（数量×単価）と合計を自動計算 |
| 売上・経費 | 日付・内容・金額・区分を登録。内容のキーワードから経費カテゴリを自動判定（材料費／送料／販売手数料・利用料／梱包資材／広告／その他）。手動で上書きも可能 |
| 原価計算 | 材料マスタ（名前・購入価格・購入数量・単位）を登録し、作品ごとの使用量から 1点あたりの原価を自動計算 |
| データ | 売上・経費の CSV 書き出し／取り込み、サンプルデータ読み込み、全データ削除 |

## 使い方

ES Modules を使っているため、`file://` で直接開くのではなく HTTP で配信してください。

```sh
npm run serve        # python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

GitHub Pages など任意の静的ホスティングにそのまま置けば動きます（ビルド不要）。

### CSV 形式

```
日付,内容,金額,区分,カテゴリ
2026-12-01,天然石ビーズ購入,1200,経費,材料費
2026-12-03,ブレスレット販売（minne）,3000,売上,
```

- 文字コードは UTF-8（書き出し時は Excel 用に BOM 付き）
- 区分は `売上` / `経費`（`sale` / `expense` も可）。カテゴリが空欄の経費は自動判定
- 英語ヘッダー（`date,description,amount,type,category`）、`¥1,200`・`2026/12/1` などの表記も取り込めます

## テスト

```sh
npm test             # ユニットテスト＋受け入れテスト（node:test、依存なし）
npm run test:e2e     # Playwright による実ブラウザのスモークテスト
```

受け入れ条件（`js/core/sample.js` のサンプルデータで検証）:

- 棚卸しの在庫金額合計 11,500円
- 売上合計 4,800円、経費合計 2,330円、利益 2,470円
- 原価：ブレスレット 1点 1,272.5円、ピアス 510円
